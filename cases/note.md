# Case Functions in SQL

- Case functions in SQL are used to provide conditional logic within a query.
- They allow you to perform different actions based on different conditions.
- CASE expressions can be used in SQL SELECT, WHERE, ORDER BY, and GROUP BY clauses.

# Window Functions in SQL

- Window functions in SQL are used to perform calculations across a set of table rows that are related to the current row.
- They operate on a "window" of rows, which are defined by a set of rows within a query result set.
- Window functions are distinct from other SQL functions because they do not cause rows to become grouped into a single output row of the query result.
- Window functions are particularly useful for performing complex calculations without using a GROUP BY clause.
